Ant Group · Multimodal UI Reasoning Model Post-training

LLM Post-training / Reinforcement Learning / Distributed Training

Sep 2026 – Present

ms-swift / SFT / GRPO / OPD / DeepSpeed / vLLM

Background: Using real Alipay user data, the project handles feedback requests. After users submit feedback and screenshots, the system interprets the UI and reasons about their situation to help troubleshoot the issue or route the feedback to the development team.

  • Post-training and alignment: Built teacher and student SFT and GRPO pipelines with a customized version of ms-swift, followed by student OPD and attention knowledge distillation. GRPO samples eight responses per question to compute group-relative advantages. In OPD, a frozen teacher supervises the student on its own sampled trajectories: reverse-KL distillation aligns output distributions, and JSD distillation of final-layer causal attention aligns where the model attends in context.
  • Distributed training and ablations: Participated in multi-GPU training, experiment replication, and result analysis for 4B and 32B models on 16 NVIDIA A100 80GB GPUs. Used DeepSpeed ZeRO sharding and gradient checkpointing to reduce memory use. GRPO and OPD used rewards for response format and answer correctness plus an overlength penalty, weighted 1.0:1.0:0.5, with dynamic sampling. Led staged ablations of SFT, GRPO, OPD, and attention distillation to isolate each stage’s contribution.
  • Data and evaluation: Cleaned internal UI data, organized evaluation sets, and evaluated models. A VLM-based automated cleaning and labeling pipeline annotated more than 570,000 examples across three task categories: element usability (232,000), information architecture (227,000), and design consistency (116,000). The 4B student gained 33.4 percentage points on an internal evaluation set; attention distillation added 2.7 points over output-only distillation. Compared with UI-TARS-7B, it scored 9.1 and 11.0 points higher on UI-Vision and OSWorld-G, respectively.
